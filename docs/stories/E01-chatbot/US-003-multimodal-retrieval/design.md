# Design - US-003 Multimodal Image Retrieval

## Domain Model

- `BgeVisualizedEmbedder`: Class mapping both visual and textual inputs into a shared 768-dimensional vector space.
- `FigureImageRecord`: Data structure containing document metadata, page number, visual descriptions, image disk path, and 768-dimensional vector embeddings.

## Application Flow

```text
User Question -> embed_text() -> Query Vector (768)
                                    |
            +-----------------------+-----------------------+
            |                                               |
            v                                               v
db.hybrid_search() (Text)                      db.image_vector_search() (Images)
            |                                               |
            v                                               v
Top Text Chunks                                Top Image Chunks
            |                                               |
            +-----------------------+-----------------------+
                                    |
                                    v
                        Render in Chatbot UI
                (Collapsible Citations showing st.image)
```

## Interface Contract

- `BgeVisualizedEmbedder.embed_text(query: str) -> List[float]`
- `BgeVisualizedEmbedder.embed_image(image_path: str) -> List[float]`
- `VectorStore.ingest_images(doc_id: str, images: List[Dict[str, Any]]) -> int`
- `VectorStore.image_vector_search(query_embedding: List[float], limit: int) -> List[Dict[str, Any]]`

## Data Model

### New Table `document_images`

```sql
CREATE TABLE document_images (
    id SERIAL PRIMARY KEY,
    document_id VARCHAR(255) REFERENCES documents(id) ON DELETE CASCADE,
    image_index INT NOT NULL,
    image_path TEXT NOT NULL,
    caption TEXT,
    vlm_description TEXT,
    page_no INT,
    embedding vector(768)
);
```

### New Index
- HNSW Index: `CREATE INDEX document_images_hnsw_cosine ON document_images USING hnsw (embedding vector_cosine_ops);`

## UI / Platform Impact

- Streamlit UI displays retrieved figures as citations using `st.image(image_path)` in the collapsible accordion.
- Renders both native Docling captions and visual descriptions generated by Qwen3-VL.

## Observability

- Logs visual model load state (devices, loading time).
- Logs time spent on visual embedding extraction and vector queries.

## Alternatives Considered

1. **Embedding images using text descriptions only**: Generating descriptions from VLM and embedding them with standard BGE-M3 text embedder. *Tradeoff*: Loses raw visual semantic similarity matching, fully dependent on the quality of Qwen3-VL descriptions. Visualized joint-embedding allows cross-modal search on layout patterns, styles, and details that description text might omit.
